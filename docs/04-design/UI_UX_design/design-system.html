Quy tắc

  • Mọi component có đủ trạng thái: default, hover, focus, active, disabled, loading, error, empty.
  • Trạng thái luôn có biểu tượng + chữ, không chỉ dựa vào màu.
  • Tương phản ≥ 4.5:1 cho chữ thường, ≥ 3:1 cho thành phần UI.
  • Chuyển động tôn trọng prefers-reduced-motion.
  • Chuỗi giao diện tiếng Việt, chừa +30% chiều rộng khi giãn chữ.
